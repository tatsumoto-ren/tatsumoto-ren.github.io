## Как внести свой вклад

Текстовые файлы этого сайта можно просматривать и редактировать
[на GitHub](https://github.com/tatsumoto-ren/tatsumoto-ren.github.io/tree/main/blog).
Чтобы предложить изменения, отредактируйте файлы Markdown.
Файлы HTML менять не нужно.
После внесения правок создайте pull request.
